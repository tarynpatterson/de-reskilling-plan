# Data Engineering Re-Skilling Plan

A structured 24-week plan to rebuild hands-on data engineering (and
analytics engineering) skills after time spent focused on analytics work.
Built for someone re-entering engineering at a Data Engineer II level —
not starting from scratch, but refreshing and modernizing.

## Why this exists

I started my data career as an analyst, moved into data engineering, and
have spent recent time doing more analytical work. This repo tracks the
plan and progress for sharpening engineering skills back up: modern
tooling (dbt, Airflow/Dagster, Spark, Iceberg/Delta, Kafka, Terraform),
multi-cloud breadth (AWS/Azure/GCP), and a portfolio of public projects.

## Goals

- Rebuild hands-on fluency in modern DE tooling: dbt, Airflow/Dagster, Spark, Iceberg/Delta, Kafka, Terraform, CI/CD.
- Demonstrate working knowledge across AWS (primary), Azure, and GCP.
- Publish a flagship end-to-end pipeline plus supporting repos that show production habits.
- Earn AWS Certified Data Engineer - Associate plus one of DP-700 or SnowPro Core.

## Definition of done for the plan

- [ ] 4 repos published with READMEs, architecture diagrams, and cost notes
- [ ] AWS DEA-C01 passed
- [ ] Second certification passed (DP-700 or SnowPro Core)
- [ ] Resume and LinkedIn updated
- [ ] 3 mock system-design interviews completed
